ВВЕДЕНИЕ

Современные системы автоматизации позволяют контролировать состояние помещений, фиксировать события и автоматически включать исполнительные устройства при возникновении заданных условий. Для учебного проекта целесообразно использовать микроконтроллер Arduino Uno, поскольку он имеет понятную архитектуру, достаточное количество цифровых и аналоговых входов и поддерживается средами моделирования.

Актуальность работы определяется необходимостью объединения датчиков различного типа в единую систему. В проекте контролируются освещённость, температура и наличие движения. Система должна выводить текущие показания и формировать событие при обнаружении движения в недостаточно освещённой зоне.

Цель курсовой работы — разработать проект аппаратно-программной системы мониторинга помещения на базе Arduino Uno по варианту 11 и подготовить комплект документации для её моделирования и проверки.

Для достижения цели необходимо проанализировать требования, выбрать компоненты, разработать схему подключений, описать алгоритм, написать программу, спроектировать базу SQLite, организовать загрузку через Node-RED и проверить нормальный и аварийный режимы.

1 АНАЛИЗ ПРЕДМЕТНОЙ ОБЛАСТИ И ПОСТАНОВКА ЗАДАЧИ

1.1 Назначение системы

Система предназначена для периодического измерения параметров помещения и регистрации результатов. В каждом цикле Arduino считывает значения с LDR, NTC и PIR, преобразует их к физическим величинам и передаёт строку DATA через последовательный порт. Если одновременно зафиксированы движение и освещённость менее 30 %, формируется EVENT THRESHOLD, а реле переводится в активное состояние. При восстановлении нормального состояния формируется EVENT NORMAL.

2 ПРОЕКТИРОВАНИЕ АППАРАТНОЙ ЧАСТИ

В качестве контроллера выбран Arduino Uno на базе ATmega328P. Плата имеет аналоговые входы, цифровые выводы, USB-интерфейс и поддерживается Arduino IDE и Wokwi.

LDR и NTC подключаются как элементы делителя напряжения. Выход делителя поступает на аналоговый вход Arduino. PIR получает питание 5 В и выдаёт HIGH при обнаружении движения. Управляющий вход реле подключается к D7 через релейный модуль. Общие выводы GND всех компонентов соединяются.

2.1 Расчёты

Разрешение десятиразрядного АЦП при опорном напряжении 5 В: ΔU = 5 / 1023 ≈ 0,00489 В. Для модели освещённость переводится линейно: L = rawL · 100 / 1023. Температура: T = rawT · 50 / 1023. Порог 30 % соответствует rawL = 30 · 1023 / 100 ≈ 307.

3 РАЗРАБОТКА АЛГОРИТМА ФУНКЦИОНИРОВАНИЯ

После включения выполняется настройка портов и последовательного интерфейса. Контроллер ожидает заданный период, считывает датчики, преобразует значения и формирует DATA. Затем проверяется условие PIR = 1 и light < 30. При переходе в аварийное состояние включаются реле и LED и выдаётся THRESHOLD. При выходе выдаётся NORMAL и устройства выключаются.

5 ПРОЕКТИРОВАНИЕ БАЗЫ ДАННЫХ SQLITE

Таблица readings содержит измерения датчиков, таблица events — переходы состояний и ошибки. Для анализа применяются запросы выбора последних измерений, вычисления MIN, AVG, MAX по датчикам и выборки аварийных событий: SELECT AVG(value) FROM readings WHERE sensor = 's1';

6 ИНТЕГРАЦИЯ С NODE-RED

Node-RED служит промежуточным слоем между журналом Serial Monitor и SQLite. Узел file in читает data/log.txt, function разбирает строки и формирует SQL, file сохраняет load.sql, exec запускает sqlite3 и выполняет транзакцию. Для DATA создаются записи readings, для EVENT — запись events. Некорректные строки пропускаются, а значения вне диапазона фиксируются как FAULT.

ПРИЛОЖЕНИЕ А. ЛИСТИНГ ПРОГРАММЫ ARDUINO

const int LDR_PIN=A0, NTC_PIN=A1, PIR_PIN=2;
const int RELAY_PIN=7, LED_PIN=13;
const unsigned long INTERVAL=15000UL;
unsigned long lastMillis=0, count=0; bool previousAlarm=false;
float mapFloat(float x,float a,float b,float c,float d){return (x-a)*(d-c)/(b-a)+c;}
void setup(){Serial.begin(9600);pinMode(PIR_PIN,INPUT);pinMode(RELAY_PIN,OUTPUT);pinMode(LED_PIN,OUTPUT);}
void loop(){
 if(millis()-lastMillis<INTERVAL)return; lastMillis=millis(); count++;
 int rawLight=analogRead(LDR_PIN), rawTemp=analogRead(NTC_PIN), motion=digitalRead(PIR_PIN);
 float light=mapFloat(rawLight,0,1023,0,100), temperature=mapFloat(rawTemp,0,1023,0,50);
 Serial.print("DATA n=");Serial.print(count);Serial.print(" s1=");Serial.print(light,1);
 Serial.print(" s2=");Serial.print(temperature,1);Serial.print(" s3=");Serial.println(motion);
 bool alarm=(motion==1 && light<30.0); digitalWrite(RELAY_PIN,alarm); digitalWrite(LED_PIN,alarm);
 if(alarm!=previousAlarm){Serial.print("EVENT n=");Serial.print(count);Serial.print(" type=");Serial.println(alarm?"THRESHOLD":"NORMAL");previousAlarm=alarm;}
}
