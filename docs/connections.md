# Таблица входных данных Python-системы

| Компонент | Тип данных | Поле Python | Назначение |
|---|---|---|---|
| LDR | входной датчик | `light` | Освещённость 0–100 % |
| NTC | входной датчик | `temperature` | Температура 0–50 °C |
| PIR | входной датчик | `motion` | Движение 0/1 |
| Реле | логический выход | `alarm` | Состояние исполнительного устройства |

Порог варианта 11: `motion == 1` и `light < 30`. Python-программа имитирует получение данных, управляет логическим состоянием реле и сохраняет результаты в SQLite.
