# Схема подключения для EasyEDA

Схема должна оформляться в стиле принципиальной схемы из примера: Arduino UNO R3 в центре, модульные датчики с контактами `SIG/VCC/GND`, метки `+5V` и `GND`, а также релейный модуль. Вариант 11 использует LDR вместо газового датчика MQ2 из примера.

| Компонент EasyEDA | Контакты модуля | Arduino UNO R3 | Назначение |
|---|---|---|---|
| Grove Light Sensor / LDR Module | `SIG`, `VCC`, `GND` | `SIG → A0`, `VCC → +5V`, `GND → GND` | Освещённость 0–100 % |
| Grove NTC Temperature Sensor | `SIG`, `VCC`, `GND` | `SIG → A1`, `VCC → +5V`, `GND → GND` | Температура 0–50 °C |
| Grove PIR Motion Sensor | `SIG`, `VCC`, `GND` | `SIG → D2`, `VCC → +5V`, `GND → GND` | Движение 0/1 |
| 1-Channel 5V Relay Module | `IN`, `VCC`, `GND` | `IN → D7`, `VCC → +5V`, `GND → GND` | Состояние исполнительного устройства |
| LED 5 mm + resistor 220 Ω | `A`, `K` | `D13 → R1 220 Ω → LED A`, `LED K → GND` | Индикация тревоги |

Порог варианта 11: `motion == 1` и `light < 30`. Если используются готовые Grove-модули, отдельные резисторы 10 кОм для LDR и NTC не нужны: они уже входят в схемы модулей. Если в EasyEDA найдутся только отдельные LDR и NTC, тогда для каждого датчика нужно добавить делитель 10 кОм.
