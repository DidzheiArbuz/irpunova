# Таблица подключений

| Компонент | Питание | Сигнал Arduino | Назначение |
|---|---|---|---|
| LDR | 5V/GND | A0 | Освещённость 0–100 % |
| NTC | 5V/GND | A1 | Температура 0–50 °C |
| PIR | 5V/GND | D2 | Движение 0/1 |
| Relay module | 5V/GND | D7 | Исполнительное устройство |
| LED | через резистор | D13 | Индикация тревоги |

Порог варианта 11: `PIR = 1` и `LDR < 30 %`. Для силовых цепей необходимо применять релейный модуль с защитой и соблюдать требования электробезопасности.
