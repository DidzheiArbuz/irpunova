# Система мониторинга помещения — вариант 11

Курсовой проект Ирпуновой Полины Дмитриевны, порядковый номер 11.

## Назначение

Система на Arduino Uno считывает:

- `s1` — освещённость с LDR, 0–100 %, вход A0;
- `s2` — температуру с NTC, 0–50 °C, вход A1;
- `s3` — движение с PIR, 0/1, вход D2.

При условии `PIR = 1` и `освещённость < 30 %` включается реле на D7 и формируется событие `THRESHOLD`. После исчезновения условия формируется `NORMAL`.

## Структура

```text
firmware/       программа Arduino
sim/             проект Wokwi
db/              схема, тестовые данные и запросы SQLite
nodered/         импортируемый flow Node-RED
data/            журналы DATA/EVENT
docs/            описание проекта и таблица подключений
```

## Запуск

1. Открыть `sim/diagram.json` в Wokwi или импортировать содержимое в новый проект.
2. Загрузить `firmware/variant11.ino`.
3. Для проверки базы выполнить из корня проекта:

```text
sqlite3 db/variant11.db ".read db/schema.sql" ".read db/load.sql" ".read db/queries.sql"
```

4. В Node-RED импортировать `nodered/flow.json`, проверить путь к `data/log.txt`, нажать Deploy.
