# Система мониторинга помещения на Python — вариант 11

Курсовой проект Ирпуновой Полины Дмитриевны, порядковый номер 11.

## Назначение

Система на Python обрабатывает данные датчиков:

- `s1` — освещённость с LDR, 0–100 %;
- `s2` — температуру с NTC, 0–50 °C;
- `s3` — движение с PIR, 0/1.

При условии `motion == 1` и `light < 30` включается логическое состояние реле и формируется событие `THRESHOLD`. После исчезновения условия формируется `NORMAL`. Для схемы EasyEDA используются готовые модульные датчики с выводами `SIG/VCC/GND`, как в предоставленном примере.

## Структура

```text
python/          программа Python
firmware/        исходный вариант аппаратной части
db/              схема, тестовые данные и запросы SQLite
nodered/         импортируемый flow Node-RED
data/            журналы DATA/EVENT
docs/            описание проекта и таблица подключений
```

## Запуск

1. Запустить Python-программу из корня проекта: `python python/monitoring_system.py`.
2. Для проверки базы выполнить из корня проекта:

```text
sqlite3 db/variant11.db ".read db/schema.sql" ".read db/load.sql" ".read db/queries.sql"
```

3. В Node-RED импортировать `nodered/flow.json`, проверить путь к `data/log.txt`, нажать Deploy.
