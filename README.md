# Вариант 11. Умная лестница

Курсовой проект по ПМ.02. Ирпунова Полина Дмитриевна.

## Входные данные

| Параметр | Значение |
|---|---|
| Сценарий | Умная лестница |
| Датчик 1 (аналоговый) | LDR, освещённость, 0–100 %, вывод A1 |
| Датчик 2 | NTC, температура, −20…80 °C, вывод A0 |
| Датчик 3 | PIR, движение, 0 или 1, вывод D2 |
| Исполнительное устройство | реле (светильник), вывод D8 |
| Светодиод / период T | красный, 15 мА, вывод D9 / 3 с (резистор 200 Ом) |
| Порог события | PIR = 1 и освещённость < 30 % |

## Ссылка на проект Wokwi

_Вставить ссылку после сохранения проекта кнопкой Share (схема — `sim/diagram.json`)._

## Файлы

- `firmware/variant11.ino` — скетч Arduino;
- `sim/diagram.json` — схема Wokwi;
- `db/schema.sql`, `db/queries.sql`, `db/load.sql`, `db/variant.db` — база данных SQLite;
- `nodered/flow.json` — flow Node-RED;
- `data/log.txt`, `data/log_fault.txt` — журнал и тест неисправности;
- `docs/` — схема EasyEDA (`schematic.pdf`), BOM, структурная схема, блок-схема, ER-диаграмма;
- `Курсовая_Ирпунова_вариант_11.docx` — пояснительная записка;
- `start-nodered.bat`, `env.bat` — запуск Node-RED и окружения.

## Порядок запуска

1. Запустить `start-nodered.bat`, открыть http://localhost:1880, импортировать `nodered/flow.json`, нажать Deploy.
2. Запустить симуляцию в Wokwi, скопировать вывод Serial Monitor в `data/log.txt`, сохранить файл.
3. Проверить данные: `sqlite3 db\variant.db ".read db\queries.sql"`.
